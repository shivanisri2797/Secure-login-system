# 🔐 Secure Login System

A simple web-based login application developed using Python Flask, SQLite, and bcrypt.

## Features
- User registration and login
- Secure password hashing
- Input validation
- SQL injection protection
- Session management and logout

## Technologies Used
- Python
- Flask
- SQLite
- bcrypt
- HTML and CSS

## How to Run
1. Install dependencies: `pip install flask bcrypt`
2. Run the program: `python3 app.py`
3. Open `http://127.0.0.1:5000` in your browser.

## Objective
To learn basic web application security and secure user authentication.
